# 드카게임즈 (Draka Games)

설치 없는 웹게임을 만드는 스튜디오의 공식 사이트.
GitHub Pages 사용자 사이트(`ageofwar-kr.github.io`)로 배포되며, 주소는 <https://ageofwar-kr.github.io/>.

## 구성
- `index.html` — 히어로, 게임 쇼케이스(도랏이 / 전쟁의 시대: 세계대전), 트레일러, 스튜디오 소개, 푸터
- `assets/css/site.css` — 디자인 시스템(다크 매트 + 게임별 포인트 컬러), 900px·640px 반응형, `prefers-reduced-motion` 대응
- `assets/js/site.js` — 내비게이션, 스크롤 리빌, 히어로 패럴랙스, 카드 틸트, 영상 지연 로드·무음 자동재생·소리 켜기·전체화면
- `assets/img/` — 도랏이 로고·스크린샷, 전쟁의 시대 포스터·플레이 화면, OG 이미지
- `assets/video/dorati-promo-1min.mp4` — 도랏이 홍보영상 60초(1080×1920)
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`

## 게임 링크
- 도랏이: <https://ageofwar-kr.github.io/dorati/> (저장소 `ageofwar-kr/dorati`)
- 전쟁의 시대: 세계대전: <https://m6msgry.sharehtml.org/> / <https://ageofwar-kr.github.io/age-of-war/>

## 메모
- 사용자 사이트 루트 저장소이므로 `/dorati/`, `/age-of-war/` 프로젝트 페이지는 각 저장소에서 그대로 배포된다.
- 페이지에는 개인정보(실명·연락처)와 관리자 관련 정보를 넣지 않는다. 개발사 표기는 `드카게임즈 (Draka Games)`만 사용한다.
