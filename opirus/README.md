# 📼 오피러스 카세트 v1.0

오피러스 1세대 **앞좌석 본 네비** 프레임 안에, **후석 7inch LCD MONITOR** 감성의 카세트 테이프 플레이어가 뜨는 PWA.

- 라이브: https://ageofwar-kr.github.io/opirus/
- 버전: v1.0

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 테이프에 곡 담기 | **SEL**(또는 **테이프 함**) → 테이프의 **＋ 곡 넣기** → 폰의 음원 여러 개 선택 |
| 테이프 넣기 | 테이프 함에서 **넣기** → `\|OPIRUS\|` 플랩이 열리며 장착 |
| 테이프 꺼내기 | **⏏ EJECT** (또는 OPIRUS 옆 슬롯) |
| 새 테이프 만들기 | 테이프 함 → **새 테이프 만들기** → 이름 + 라벨 색(크림·골드·레드·블루·그린) |
| 되감기 / 빨리감기 | **◀◀ / ▶▶** 한 번 = 10초, 꾹 누르면 계속 감기 |
| 재생 / 멈추기 | 가운데 큰 버튼 |
| 전원 | **PWR** — 끄면 화면이 꺼지고, 켜면 부팅 화면(약 1.5초, 탭하면 건너뜀) |

기본으로 빈 테이프 3개(**클래식 50곡 · 트로트 · 긴 뽕짝**)가 들어 있습니다. 한 곡짜리 긴 메들리 파일도, 수십 곡도 같은 방식으로 담깁니다.

## 저장 방식

- 만든 테이프는 **이 기기 브라우저의 IndexedDB**에만 저장됩니다(음원 Blob + 목록).
- 서버 업로드는 없습니다. 고른 파일은 기기 밖으로 나가지 않습니다.
- 많은 곡은 **한 파일씩 순서대로** 저장하며 `저장 중... 12/50`처럼 진행률을 보여 줍니다.
- 테이프를 지우면 그 안의 음원도 함께 지워집니다. 새로고침해도 테이프와 마지막에 넣은 테이프가 유지됩니다.

## 파일 구조

```
opirus/
├─ index.html        본 네비 프레임 + LCD 덱 + 시트(테이프 함·만들기·안내)
├─ css/style.css     전체 스타일(단위 --u = 네비 폭의 1%)
├─ js/app.js         테이프 보관/재생/삽입·꺼내기/부팅/미디어세션
├─ manifest.json     PWA 매니페스트(standalone, orientation any)
├─ sw.js             서비스워커(네트워크 우선)
├─ icon-*.png        앱 아이콘(192/512/마스커블) + apple-touch-icon
├─ favicon.svg
└─ tools/
   ├─ make-icons.py  아이콘 재생성 스크립트
   └─ check.py       자동 검증 스크립트(로컬/라이브)
```

정적 자산은 `?v=NNN` 쿼리로 캐시를 갱신합니다. 수정 후 `index.html`과 `sw.js`의 버전을 함께 올려 주세요.
